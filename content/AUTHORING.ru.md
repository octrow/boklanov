# Как редактировать сайт boklanov.com

> Источник правды — папка `content/productions/`. Там лежит по одному
> файлу на спектакль (`index.mdx`). Редактируем в Obsidian, публикуем
> кнопкой «Commit + Push» — сайт пересобирается автоматически через 1–2
> минуты.

---

## Один раз: установка

### 1. Установить Obsidian

Скачать с [obsidian.md](https://obsidian.md) — бесплатно, macOS / Windows / iOS / Android.

### 2. Получить от Daniil: Personal Access Token

GitHub PAT нужен для записи. Daniil создаёт токен на своей стороне и
отправляет тебе в Telegram. Хранить токен в безопасном месте (Keychain,
1Password, заметка под замком). Если потерял — Daniil выдаст новый.

### 3. Открыть хранилище (vault) в Obsidian

Хранилище — это весь репозиторий. Два варианта:

**Вариант A — репозиторий уже есть на компьютере:**

1. Obsidian → **Открыть другое хранилище** → **Открыть папку как
   хранилище** → выбрать папку `boklanov` (ту, что уже склонирована).

**Вариант B — первая установка, репозитория нет:**

1. Сначала склонировать репозиторий через Terminal:
   ```bash
   git clone https://github.com/octrow/boklanov.git
   cd boklanov
   ```
   При запросе пароля — вставить PAT.
2. Затем Obsidian → **Открыть папку как хранилище** → выбрать `boklanov`.

### 4. Включить плагины

Obsidian предложит включить сторонние плагины из репозитория. Согласиться
для обоих:

- **obsidian-git** — кнопка «Commit + Push» в боковой панели.
- **mdx-as-md** — позволяет открывать `.mdx`-файлы как обычный Markdown.

Если Obsidian не спросил автоматически: **Настройки** (шестерёнка) →
**Сторонние плагины** → убедиться, что оба плагина включены.

### 5. Настроить obsidian-git

Первый раз плагин попросит авторизацию:

- **Имя пользователя:** твоё имя (например, `Roman Boklanov`)
- **Email:** твой GitHub email
- **Пароль / токен:** PAT от Daniil

### 6. Obsidian Mobile (опционально)

На телефоне: App Store / Google Play → «Obsidian». Повторить шаги 3–5.
На мобильном удобно исправлять текст; большие правки (новые спектакли,
загрузка фото) — только с компьютера.

## Каждый день: как что-то изменить

### Изменить поле спектакля

Поля — это структурированные данные: год, театр, возраст, флаг «главный»,
список городов гастролей и т.д.

1. В левой панели Obsidian открыть `content/productions/<slug>/index.mdx`.
   Например: `content/productions/bury-me-behind-the-baseboard/index.mdx`.
2. В самом верху файла — панель **Properties** (серая область с полями).
   Если не видна: правый клик на заголовок → **Show frontmatter**.
3. Кликнуть на нужное поле, ввести новое значение, **Cmd+S** (Ctrl+S на
   Windows).
4. В правой боковой панели — иконка **Source Control** (веточка git) →
   **Commit all changes** → ввести описание («исправил год кашт…») →
   **Commit-and-sync**.
5. Через 1–2 минуты Vercel пересобирает сайт. Открыть
   [boklanov.com](https://boklanov.com) и убедиться, что изменение видно.

**Главные поля (то, что редактируется чаще всего):**

| Поле               | Что это                                    | Пример                                 |
|--------------------|--------------------------------------------|----------------------------------------|
| `title.ru`         | Название на русском                        | `Золушка`                              |
| `title.en`         | Название на английском                     | `Cinderella`                           |
| `synopsis.ru`      | Краткое описание (RU)                      | _несколько предложений_                |
| `synopsis.en`      | Краткое описание (EN)                      | _перевод_                              |
| `year`             | Год премьеры                               | `2021`                                 |
| `ageRating`        | Возрастное ограничение                     | `6+`                                   |
| `durationMin`      | Длительность в минутах                     | `60`                                   |
| `featured`         | Показать на главной                        | `true` / `false`                       |
| `tour`             | Города гастролей «Плинтуса»                | список                                 |
| `directorsNote.ru` | Записка режиссёра под синопсисом           | _текст курсивом_                       |
| `runs`             | Цифры прокатов (появляется над заголовком) | `venue, city, yearFrom, yearTo, count` |
| `theatre.name`     | Театр-постановщик                          | `ARTиШОК`                              |
| `theatre.url`      | Сайт театра                                | `https://artishock.kz/`                |

### Изменить текст описания / синопсис

1. Тот же файл, прокрутить ниже серой области Properties.
2. Там — обычный текст, редактировать как в Word.
3. **Cmd+S** → **Commit-and-sync**.

### Добавить фотографии на страницу «О режиссёре»

Фото появляются в двухколоночной сетке под блоком «Где ставил».

1. Положить файлы в `public/about/` (форматы `.webp`, `.jpg`).
2. Открыть `content/about/ru.mdx` в Obsidian, найти поле `photos` в Properties.
3. Добавить запись:
   ```
   - src: /about/имя-файла.jpg
     credit: "Имя Фотографа"
   ```
4. Повторить для `content/about/en.mdx` — те же записи.
5. **Cmd+S** → **Commit-and-sync**.

Пустой список `photos: []` = секция не отображается.

### Добавить новый спектакль

1. Найти похожий спектакль как шаблон, например
   `content/productions/lina-marlina/`.
2. Скопировать всю папку, переименовать в новый slug (латиница, дефисы
   вместо пробелов; пример: `solnyshko`, `novaya-postanovka`).
3. Открыть `index.mdx` в новой папке, заполнить все поля Properties,
   написать описание.
4. Положить фотографии в ту же папку (форматы: `.webp`, `.jpg`).
5. В поле `gallery` в Properties добавить записи вида:
   ```
   - src: /productions/<slug>/01.jpg
     credit: null
     caption:
       ru: null
       en: null
   ```
6. Написать Daniil — он загрузит фото в R2 командой `npm run upload-images -- --slug <slug>`.
7. Commit-and-sync — сайт пересобирается, новый спектакль появляется на
   `/ru/productions`.

### Заменить или добавить фотографии существующего спектакля

1. Положить новые файлы в `public/productions/<slug>/`.
2. Удалить старые файлы из той же папки (если заменяешь).
3. Обновить поле `gallery` в `index.mdx` — список `src` должен
   соответствовать файлам в папке.
4. Написать Daniil — он загрузит новые фото в R2 (`npm run upload-images -- --slug <slug>`).
5. Commit-and-sync.

## Черновики (если правка большая или сомнительная)

Например, добавляешь три новых спектакля и не уверен в текстах.

1. В Source Control → **кнопка «ветка»** → создать ветку `draft/<описание>`.
   Например: `draft/three-new-shows`.
2. Все правки коммитятся в эту ветку. Vercel создаёт **отдельный preview
   URL** — автоматически, прилетает ссылкой в GitHub. Открыть, проверить.
3. Если всё ок: написать Daniil, он смержит ветку в `main`.
4. Если не ок: продолжить редактировать либо удалить ветку (ничего не
   пропадёт в `main`).

## Что-то сломалось

**Сайт не обновился через 5 минут**
→ Открыть [github.com/octrow/boklanov/actions](https://github.com/octrow/boklanov/actions).
Красный значок = билд упал. Скопировать ошибку → Daniil.

**obsidian-git ругается «merge conflict»**
→ Не паниковать. Нажать **Pull** (стрелка вниз) в Source Control, потом
написать Daniil — он покажет, как разрешить конфликт за 2 минуты.

**Случайно опубликовал что-то лишнее**
→ Всё в порядке. Поправить и сделать новый commit-and-sync.
История в git — ничего не теряется.

**Забыл PAT**
→ Написать Daniil — выдаст новый за пару минут.

**Obsidian не открывает `.mdx` файлы как текст**
→ Убедиться, что плагин `mdx-as-md` включён. Если нет:
**Настройки → Сторонние плагины → mdx-as-md → включить**.
