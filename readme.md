# boklanov.ru

Personal site for **Roman Boklanov** — theatre director (puppet theatre,
theatre of objects, contemporary theatre for kids / teens / family).
Bilingual RU/EN with German chrome. Static, content-owned, editorial.

> **Branch state:** v2 rewrite lives on `rewrite/v2` and is the deploy
> candidate. The legacy `react-notion-x` runtime renderer was retired in
> Phase F8; everything below describes the current build.

---

## Stack
- **Framework:** Next.js 15 (App Router) + React 19 + TypeScript 5.9 (strict)
- **i18n:** `next-intl` v4 — RU canonical at `/`, EN at `/en`, DE at `/de`
- **Content:** MDX per production + per-production `metadata.yml` overlay,
  loaded by `lib/content.ts`. No CMS, no runtime API. Statically
  prerendered — 24 productions × 3 locales = 72 detail pages, plus
  per-locale chrome (home, about, awards, press, contact, archive,
  productions grid).
- **Styling:** CSS Modules + design tokens (`app/globals.css`, custom
  properties only — no Tailwind, no styled-components)
- **Typography:** self-hosted Lora (display) + Inter (body) + JetBrains Mono
  (metadata) under `public/fonts/`, OFL, locale-aware preload
- **Imagery:** `next/image` (AVIF/WebP), `sharp`-generated LQIP placeholders
- **Search:** Cmd-K palette with Cyrillic↔Latin transliteration
  (`lib/search.ts`, `components/CommandPalette.tsx`)
- **Analytics:** PostHog, single event (`booking_cta_click`); no autocapture,
  no recording, silent no-op without an API key

Quality bars in place: zero `DESIGN.md` §11 anti-patterns, Lighthouse
mobile ≥ 95, AA contrast, focus ring on every interactive element,
`prefers-reduced-motion` honoured at the token level.

## Local development

```bash
npm install                # Node ≥ 22, npm ≥ 10
npm run sync               # parse notion-data/, regenerate content/, write public/
npm run dev                # http://localhost:3000
npm run build && npm start # production check before deploying
```

`npm run sync` is the only command that mutates `content/` and
`public/productions/`. Re-run after re-exporting from Notion.

### Linting & type-checking

```bash
npm run lint
npm run typecheck
```

Both run clean under `strictNullChecks` without escape hatches —
keep it that way (`next.config.js` does not set `ignoreBuildErrors`
or `ignoreDuringBuilds`).

## Editing content

Two surfaces, one rule: **MDX regenerates, `metadata.yml` survives.**

- **Add / update productions, photos, awards** → re-export the Notion
  database to a fresh `notion-data/` ZIP, drop it in, run `npm run sync`.
  The script regenerates `content/productions/<slug>/index.mdx`,
  copies images to `public/productions/<slug>/`, generates LQIP
  placeholders, and emits stub `metadata.yml` files for new productions.
  Existing `metadata.yml` is **not touched**.

- **Hand-fixes that must survive re-sync** → edit
  `content/productions/<slug>/metadata.yml`. The loader merges it on
  top of the generated MDX with overlay-wins semantics.

- **Featured shows on the home page** → set `featured: true` in
  `metadata.yml`. Brief target is 4–6 hand-curated cards drawn from
  the top-coverage band (see `.design/boklanov-rewrite/photo-audit.md`).
  Cards without a poster are filtered out of the featured strip
  (`getAllProductions().filter(p => p.featured && p.poster.src)`).

- **About-page bio + milestones + lineage** → edit
  `content/about/{ru,en,de}.mdx` directly. These are not generated.

- **UI chrome strings (nav, buttons, chip labels)** → edit
  `messages/{ru,en,de}.json`. RU + EN required, DE chrome-only for v1.

- **Production-card text never translates to DE** by design (IA D4): the
  card stays RU/EN; only the surrounding chrome flips to German.

Detailed authoring rules + frontmatter shape live in `content/README.md`.

## Design system

Source-of-truth chain (each downstream doc may refine, never contradict):

```
DESIGN_BRIEF.md  (locked decisions, why)
   ↓
DESIGN.md        (visual identity, how it looks and feels)
   ↓
tokens.css / tokens.md   (runnable values + reference)
   ↓
app/globals.css  (integration target — every component reads --* tokens)
```

Hard rules from `DESIGN.md`:

- **Photo-led colour:** chrome stays neutral; colour comes from production
  photos. The single accent (oxblood `#6B0F0F` light / `#A82626` dark)
  appears in **three places only** — booking CTA fills, primary-link
  hover underline, focus ring.
- **No glassmorphism, no AI-purple gradients, no `rounded-2xl shadow-xl`,
  no hero video, no bento grids, no animated gradient text** — full
  anti-pattern list in `DESIGN.md` §11.
- **Sharp corners** (max radius 2px on chips), **hairline rules** for
  layering (no shadows for separation), **mono everywhere a number
  isn't a price**.

Component build order, breakpoints, motion budget, accessibility floor,
imagery rules — all in `DESIGN.md`.

## Deploy

Phase 7 status: **R2 (real-device QA)** and **D1 (Vercel preview)** are the
remaining tasks. Hosting target is Vercel pending D2 confirmation
(Cloudflare Pages and Yandex Cloud are alternates if RU/CN edge access

```bash
# production
vercel deploy --prod
```
