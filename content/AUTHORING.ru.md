# Как редактировать сайт boklanov.com

> Источник правды — Postgres (Neon). Редактируется через веб-форму на
> `boklanov.com/admin`. Сайт пересобирается автоматически через
> несколько секунд после нажатия «Сохранить» — git не нужен,
> устанавливать ничего не надо.

---

## Один раз: вход

1. Открыть `https://boklanov.com/admin` (на телефоне тоже работает,
   но удобнее с ноутбука).
2. Войти по email + паролю (Daniil выдал при первом запуске; пароль
   меняется в `/admin/account`).
3. В верхнем правом углу — переключатель языка интерфейса (RU / EN).
   По умолчанию русский.

Если забыл пароль — попросить Daniil сбросить через `npx tsx scripts/...`
(вручную, без Forgot-password UI).

## Каждый день: как что-то изменить

### Изменить поле спектакля

1. Слева: **Контент → Спектакли**.
2. Кликнуть нужный спектакль (русское название — в первой колонке).
3. Сверху — табы: **Основное / Медиа / Продакшен / Таксономия /
   Команда / Признание / История / Настройки**. Перейти на нужный таб.
4. Изменить значение.
5. Над формой — переключатель локали `RU / EN / DE`. Сменить, чтобы
   править ту же запись в другом языке. Поля, которые видно сразу
   во всех трёх локалях, делятся между ними — общие; остальные
   привязаны к выбранной локали.
6. Внизу справа — кнопка **Сохранить**. Сохранение пишет в Postgres,
   и сайт обновляется в течение нескольких секунд (revalidate-хуки
   сбрасывают кеш Next.js).

Под кнопкой «Сохранить» — индикатор: «Изменения не сохранены» / «Saved».

### Добавить новый спектакль

1. Слева: **Контент → Спектакли** → **Создать** (правый верхний угол).
2. Сначала заполнить:
   - **URL-слаг** (Tab «Основное»): латиница, дефисы, без пробелов.
     Например `bury-me-behind-the-baseboard`. Меняется на странице
     после публикации — лучше выбрать сразу окончательный.
   - **Название** (RU / EN / DE по локалям).
3. Сохранить. Появится URL `/{locale}/productions/<slug>` — можно
   открыть в новом табе и листать live-preview справа в форме.
4. Постепенно дополнять остальные табы. Картинки — через кнопки
   **Загрузить**/**Очистить** в полях `media.poster`, `media.gallery` и т. п.

### Картинки

В полях `Постер`, `Обложка для каталога`, `Обложка для главной` и
в массиве `Галерея` — кнопка **Загрузить**. После загрузки файл уходит
на R2 (`boklanov-content` бакет), показывается превью прямо в форме.
Кнопка **Очистить** убирает ссылку (но не удаляет файл с R2).
**Удалить** убирает файл с R2 насовсем — обратной кнопки нет, осторожно.

### Страница «О режиссёре»

Слева: **Контент → Страница «О режиссёре»**. Тоже разделена на табы:

- **Био** — биографический текст (один большой `textarea` по локалям).
  Первый абзац — лид (рендерится крупно). Поддерживается обычный
  markdown.
- **Визуал** — портрет + галерея фото.
- **Хронология** — вехи (год + подпись) и преемственность (учителя
  / школы).
- **Заметки** — короткие пометки на полях рядом с абзацами
  биографии. Один абзац — одна заметка (или `null` если без неё).

### Страница «Контакты»

Слева: **Контент → Контакты**. Четыре поля:

- **Вступительный текст** (необязательно)
- **Эл. почта** (обязательно — используется в `mailto:`)
- **Telegram URL** — полный URL вида `https://t.me/roman7593`
- **Instagram URL** — полный URL

### Витрина (главная страница)

Чтобы спектакль появился на главной в featured-strip:

1. Открыть спектакль → таб **Настройки**.
2. Включить тогглер **На главной**.
3. Появится поле **Порядок на главной** — число от 1; меньше = раньше
   на ленте.
4. Сохранить.

Если у спектакля нет постера (`media.poster.src` пустой) — он не
покажется на главной даже с включённым тогглером (защита от пустых
карточек).

## Какие поля видны во всех локалях, а какие — нет

| Поле                                         | Локализуется  | Пояснение                                        |
| -------------------------------------------- | ------------- | ------------------------------------------------ |
| `identity.title` / `tagline` / etc.          | да            | по три значения на спектакль                     |
| `production.theatre.name`                    | да            | три варианта названия театра                     |
| `production.theatre.city`                    | да            | «Москва» / «Moscow» / «Moskau»                   |
| `production.theatre.country`                 | **нет**       | ISO-2 (RU / KZ / DE …) — общий для всех локалей  |
| `production.theatre.url`                     | нет           | URL общий                                        |
| `media.poster.src`                           | нет           | картинка одна                                    |
| `media.poster.credit`                        | нет           | имя фотографа                                    |
| `media.gallery[].caption`                    | да            | подписи к фото — по локалям                      |
| `taxonomy.role` / `form` / `lineage`/ `tags` | нет           | технические ярлыки (`director`, `puppet`, `btk`) |
| `team.creditsRu` / `En` / `De`               | (три массива) | каждая локаль — отдельный массив                 |

Когда правишь не-локализованное поле в любой локали — изменение видно
сразу во всех трёх локалях.

## Live preview

В правой части формы — окошко с предпросмотром страницы. Доступны три
размера: мобильный (390), планшет (768), десктоп (1440). Это та же
страница `/{locale}/productions/<slug>`, что видит посетитель сайта.
Обновляется без сохранения — пока правишь, видно черновик; чтобы
зафиксировать, нажми «Сохранить».

## Если что-то не так

- **«Изменения не сохранены»** не уходит после Save → подожди пару
  секунд (сетевой запрос). Если виснет — обнови страницу; данные не
  пропадают (Payload пишет в Postgres).
- **На сайте старые данные** → revalidate-хук иногда промахивается.
  Помогает редактирование любого ненужного поля и Save заново. Если
  не уходит — Daniil дёрнет руками.
- **Картинка не появляется** → проверь, что `cdn.boklanov.com` DNS
  поднят (`NEXT_PUBLIC_CDN_BASE` в Vercel). До этого изображения
  отдаются из dev-URL R2 (медленнее, но работает).
- **Удалил случайно поле / спектакль** → у Payload есть undo на
  ближайшее изменение, но не на удаление целиком. Если удалил
  спектакль и захотел вернуть — пиши Daniil, восстановим из бэкапа
  Neon.

## Чего больше нет

- `content/productions/<slug>/index.yaml` + `body.{ru,en,de}.md` —
  удалены 2026-05-14 после перехода на Payload. История в git.
- Obsidian / `obsidian-git` — больше не нужны. Если стоит — снести,
  чтобы не путалось.
- Keystatic (`boklanov.com/keystatic`) — выключен. Закладку убрать.
- Personal Access Token GitHub — больше не нужен; редактирование не
  идёт через git.
